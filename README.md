# review-deconstruction

一个 [WorkBuddy](https://www.workbuddy.cn) Skill：**综述拆解法**——系统性拆解综述论文的"写作工艺"（结构、分类法、叙事技巧、图表设计、缺口写法），帮你在写自己的文献综述之前，从范文中提取可复用的写作决策。

A WorkBuddy skill for deconstructing review/survey papers to learn their **writing craft** — structure, taxonomy, narrative techniques, figure/table design, and gap-statement construction — before writing your own literature review.

## 核心理念 / Core Principle

> 读普通论文是"读内容"，读综述是"读写法"。
> Read ordinary papers for content; read reviews for craft.

每篇拆解必须落到具体决策：**抄 3 样、避 2 样**。
Every deconstruction ends with concrete decisions: copy 3 things, avoid 2 things.
